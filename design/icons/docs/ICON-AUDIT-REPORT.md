# SVG 图标库审查与重设计记录

版本：v1.2.0  
审查范围：全部 77 个 SVG 图标（逐个渲染总览，并进行 XML/SVG 结构检查）

## 本轮重点重设计

| 图标 | 处理 | 设计语义 |
|---|---|---|
| broadband | 重绘 | 地球 + 以太网接头，表达 WAN/宽带接入 |
| network-settings | 重绘 | 网络节点拓扑 + 设置节点，区别于系统设置 |
| rules-refresh | 重绘 | 规则列表 + 明确循环刷新箭头 |
| ipv4 / ipv6 | 重绘 | 协议标签框内使用清晰的 IP + 4 / 6 单线矢量字形，避免依赖字体渲染 |
| system-update | 重绘 | 系统文档/界面 + 向上更新箭头 |
| package-update | 重绘 | 软件包立方体 + 更新箭头，与系统更新区分 |
| restart-network | 重绘 | 网络服务重启循环语义 |
| restart-router | 重绘 | 路由器设备 + 独立重启箭头，减少交叠 |
| system-settings | 新增 | 独立系统设置滑杆图标，不与网络设置混用 |

| shutdown | 重绘 | 电源符号 + 关机动作提示，与通用电源区分 |
| status-offline | 重绘 | 断开的网络连接，区别于错误状态 |

## 统一规范

- viewBox：24×24；width/height：24
- 默认描边：2px；round cap / round join
- 颜色：currentColor；不写死品牌色
- IPv4 / IPv6 使用纯 SVG 路径，不依赖系统字体，不使用模糊的小字号文字
- 预览页和 sprite 根据 manifest 同步生成

## 审查说明

本轮对 76 个原图标全部生成 96px 渲染总览，逐项检查名称与视觉语义；针对语义易混、形态重叠或可读性不足的项目进行重绘。未被列入重绘表的图标保留原始路径。SVG 文件均需通过 XML 解析及结构一致性检查；具体产品页面中的最终显示仍应按 16/20/24/32px 实际尺寸验收。
