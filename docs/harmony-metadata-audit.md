## 2. 文案草稿（可直接用，也可改）

**一句话简介**（≤30 字）

> 在手机上管理 iStoreOS / OpenWrt 路由器：状态、设备、代理、拦截。

**完整介绍**（草稿，约 300 字）

> iStore Pilot 是 iStoreOS / OpenWrt 路由器的第三方管理客户端，配合跑在路由器上的
> 轻量 Agent 使用。界面为原生开发，非网页套壳。
>
> 主要功能：
> - **概览**：CPU / 内存 / 磁盘负载、实时流量曲线、宽带连接状态与公网地址
> - **设备**：在线设备清单、每台设备的实时上下行、按设备查看流量与连接，可一键禁止某台设备上网
> - **代理**：查看 OpenClash / Passwall 运行状态，切换节点、切换后端、看实时连接与延迟
> - **拦截**：AdGuard Home 的查询量、拦截率、拦截日志，可接管全屋 DNS（带二次确认）
> - **诊断与备份**：ping / traceroute / DNS 查询，配置备份与恢复，网口与 WAN 设置
>
> 说明：
> - 本应用**不是** iStoreOS 官方产品，为其生态内的第三方客户端
> - 需要在同一网络（或已配置好的外网地址）下连接到运行 iStore Agent 的路由器才能使用，
>   单独安装本应用无法体验任何功能
> - 不收集、不上传任何个人数据，所有信息只在本机与你的路由器之间传输（详见隐私政策）

**新版本特性（0.1.7）**：直接取 `CHANGELOG.md` 的 0.1.7 段，删掉内部术语（如
`@ComponentV2`、`AppStorageV2`）保留用户可感知的：DNS 不再受代理开关影响、
概览页地址显示修复、鸿蒙界面卡片对齐。

## 3. 三条必须避开的表述

华为审核对下面这类词是**直接判"误导"**的：

| 不能写 | 原因 | 改写成 |
|---|---|---|
| 官方客户端 / 官方出品 | 暗示官方授权 | 第三方客户端 / 生态客户端 |
| 最好用 / 最强 / 首选 | 夸大宣传、无法证实 | 删除 |
| 免费、永久免费 | 名称与信息里的价格营销词 | 删除（价格信息放 AGC 定价页） |

## 4. 最大的坎：审核员怎么登录？（需要你拍板）

这不是文档问题，是**产品形态问题**。审核员拿到 App，打开是登录页，需要路由器地址 + 口令；
他没有你的路由器，也没有你的口令。三个方案：

| 方案 | 做法 | 成本 | 风险 |
|---|---|---|---|
| **A. 公网演示实例**（推荐） | 在云主机上跑一个 Agent，接**模拟数据源**（不连真路由器），给 AGC 填一组演示地址 + 口令 | 中：要给 Agent 加一个 `--demo` 数据源（现在所有数据都来自 ubus/uci/nft，非 OpenWrt 环境会全报错） | 演示数据要看起来真实，否则审核可能判"功能与描述不符" |
| **B. 只给演示视频 + 说明** | 在 AGC 说明"需自建服务端"，配 3~5 分钟视频 | 低：只录视频 | **高**：审核员无法自行验证，大概率驳回并要求提供测试账号 |
| **C. 内置演示模式** | App 里加"先看看演示"入口，走本地假数据 | 高：三端都要改，还要防止被当成真实功能 | 低（对审核最友好） |

我的判断：**A 最划算**。Agent 的接口层已经和取数层分开（`agent/` 里 modules 各自
返回 dict），加一个 `--demo` 分支（返回固定 JSON）比改三端都便宜；而且演示实例还能
给你自己当回归环境用。

## 5. 需要填写用途的权限

从 `harmony/entry/src/main/module.json5` 与实际功能核对，提审时要逐条写中文用途：

| 权限 | 用途说明（可直接抄） |
|---|---|
| `ohos.permission.INTERNET` | 连接你局域网内 / 已配置的 iStore Agent 以读取路由器状态、下发设置 |
| `ohos.permission.GET_NETWORK_INFO` | 判断当前是否在同一局域网，决定用内网地址还是外网地址连接 |
| （若有）通知类权限 | 用于后台任务失败、证书即将过期等提醒 |

**不需要**位置、通讯录、相册、麦克风——提审时若被问到，明确写"不申请"。
