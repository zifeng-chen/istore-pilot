# 演示模式（鸿蒙 · 应用商店审核用）

审核员没有你的路由器 —— 打开 App 就停在登录页，进不去就驳回。
演示模式把**真机录下来的接口返回**打包进 App，审核员点一次就能把四个页签看完。

> 只做鸿蒙。Android / iOS 没有这个入口，包里也不带 `demo.json`
> —— 那两个平台按各自的审核流程走，不为此多背 140 KB。

## 一、审核员怎么用

1. 打开 App → 停在登录页
2. 勾选「我已阅读并同意《用户协议》和《隐私政策》」
3. 点「没有路由器？先看看演示 →」

进入后顶部是概览、设备、代理、设置四个页签，数据完整（52 台设备、两个代理后端、
拦截日志与热门域名、硬件信息、订阅列表都在）。概览页右上角的版本胶囊显示
**「演示数据」**，一眼能看出不是真机。

任何写操作（重启、禁网、启停代理、更新订阅、上传安装包）都会提示
**「演示模式只能浏览，这项操作需要连接真实路由器」**，不会假装成功。

退出：设置 → 底部「退出演示」。

## 二、审核备注（AGC `appRemark` 建议文案）

```
本应用是 iStoreOS 路由器的局域网管理工具，需要用户自建路由器并安装配套
Agent 才能使用，因此审核时无法连接真实设备。

请在登录页勾选协议后点击「没有路由器？先看看演示」进入演示模式：
- 数据为真机录制并脱敏的示例，只读；
- 可浏览概览、设备、代理、设置四个页签的全部界面；
- 所有写操作会提示「演示模式只能浏览」。

应用不含任何账号体系，不收集个人信息，无第三方 SDK，不提供互联网信息服务。
```

## 三、数据从哪来

```
ROUTER_PW=口令 python scripts/record_demo.py
```

一条命令做三件事：登录路由器 → 逐接口录制 → 脱敏后写出鸿蒙资源：

| 端 | 落点 |
|---|---|
| 鸿蒙 | `harmony/entry/src/main/resources/rawfile/demo.json` |
| Android / iOS | 不生成 |

录制内容：36 个只读接口（概览 / 设备 / 代理 / 拦截 / 硬件 / 网络 / 存储 /
更新 / 订阅 / 节点分组 / 拦截日志与热门域名 / 设备详情 ×3）。写接口不录。

## 四、脱敏规则

`agent/demo.py` 的 `Store.scrub()` 负责通用部分（MAC、内网/公网地址、主机名、
订阅 URL），`scripts/record_demo.py` 的 `sanitize()` 再补这个 App 特有的三类：

| 类别 | 举例 | 换成 |
|---|---|---|
| 机场痕迹 | `🇯🇵日本高速01\|CTCU\|0.5x` | `🇯🇵演示节点 01` |
| | `我的良心云` | `演示分组 01` |
| | `三毛V2.0.yaml` | `演示配置 01.yaml` |
| | `良心云` + `liangxin.xyz` | `演示订阅 01` + `example.com` |
| 上网行为 | `galileotelemetry.tencent.com` | `site37.example.com` |
| | `百度` + `mobads.baidu.com` | `演示应用 01` + `site01.example.com` |
| 用户起的名 | 设备别名 `绿联nas` / 厂商 `格力` | `演示设备 01` / `演示厂商` |

同一台设备 / 同一个域名在**所有接口里保持同一个假值**，否则界面会出现
「当前节点在列表里找不到」这种自相矛盾。

保留原样的：协议内置策略名（`DIRECT` / `REJECT` / `GLOBAL`）、品牌域名
（`istoreos.com` / `github.com`）、规则表名（`anti-AD` 等公开规则集）。

## 五、鸿蒙实现

| 文件 | 职责 |
|---|---|
| `core/Demo.ets` | 读 rawfile、按路径取数、开关落盘 |
| `api/Api.ets` | GET 走包内数据，POST / 上传直接拒绝 |
| `pages/LoginPage.ets` | 「没有路由器？先看看演示 →」入口（要先勾协议） |
| `pages/Index.ets` | 冷启动恢复演示态 |
| `ui/tabs/OverviewPage.ets` | 版本胶囊显示「演示数据」 |
| `ui/tabs/SettingsPage.ets` | 地址显示「本地示例数据」、「退出演示」 |

要点：

- 路径 → key 的规则和录制脚本的 `_key()` 对齐（非字母数字压成下划线）；
- 精确 key 没命中时按路径前缀回退（`devices/detail?mac=xx` 只录了 3 台）；
- 演示模式下**不读也不写真实快照**，避免先闪一下上次连真机的数据；
- 数据懒加载：只有真的是演示态才解析那 140 KB，正常连接的用户不付这个启动开销；
- 演示态的 `Session.base` 是占位符 `demo`，请求在 `Api` 层就拦掉了，一个包都不会发。

## 六、重录时机

- 接口加了新字段 / 新接口 → 重录
- 路由器换了设备（设备数、网口数变化）→ 重录
- 发版前核对一次：`python scripts/record_demo.py` 会打印每个接口的大小，
  失败接口超过 4 个会返回非 0
