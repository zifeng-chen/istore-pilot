iStore Pilot 用户协议

生效日期：2026 年 11 月 11 日 适用版本：0.3.0 及以后 开发者：chaof（个人开发者）
本协议是你与 iStore Pilot（以下简称「本应用」）开发者之间就使用本应用达成的约定。
请在使用前仔细阅读。你开始使用本应用，即视为已阅读并同意本协议全部内容。

一、本应用是什么

本应用是 iStoreOS / OpenWrt 路由器的第三方管理客户端。它本身不具备联网服务端， 必须配合安装在你自己路由器上的 iStore Agent 组件使用。你需要在应用内填写 路由器的地址与登录口令，应用才能读取状态、下发设置。

本应用不是 iStoreOS、OpenWrt 或其所属组织的官方产品，与上述组织无隶属或代理关系。 相关名称仅用于说明本应用的兼容范围。

二、使用前提

  • 你需要自行准备并维护一台可运行 iStoreOS / OpenWrt 的路由器，并在其上完成 iStore Agent 的安装与配置
  • 你需要自行保证手机与路由器之间的网络可达（同一局域网，或你自行配置的远程访问方式）
  • 你需要妥善保管路由器登录口令与 App 登录口令，因口令泄露造成的后果由你自行承担

三、你可以做什么

在遵守本协议与适用法律法规的前提下，你可以：

  • 在自己的设备上安装、使用本应用，管理你自己的路由器
  • 按项目开源许可（MIT）的条款获取、修改、分发本应用的源代码
  • 通过项目仓库的问题反馈渠道提出建议或报告缺陷

四、你不应做什么

  • 不得使用本应用管理你无权管理的路由器或网络设备
  • 不得利用本应用从事任何违反法律法规、侵害他人合法权益的活动
  • 不得对本应用进行反向工程后用于商业分发（开源许可另有约定的除外）
  • 不得删除或遮蔽本应用中的版权声明与许可声明

五、风险提示

本应用会向你的路由器下发配置变更（修改口令、调整网络参数、启停代理与拦截服务等）。 这类操作可能导致路由器重启、断网、局域网内其他设备暂时失联。 请在操作前确认你了解该操作的影响，并确保自己能够通过物理接触或其他方式恢复设备。
  • 本应用与路由器之间的通信默认为 HTTP 明文。若你在不可信网络中远程访问， 请自行在路由器侧配置 HTTPS 反向代理或使用 VPN。应用内对此也有相应提示。
  • 本应用展示的所有数据均来自你自己的路由器，其准确性取决于路由器侧的采集结果， 开发者不对数据的完整性、实时性作出保证。
  • 代理、DNS、拦截类功能的实际效果取决于第三方软件与你的网络环境， 开发者不对其可用性、速度或合规性作出承诺。
