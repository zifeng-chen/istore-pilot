# 三端 UI 一致性审查规范

> 借鉴 [wg-skills](https://github.com/jiushiwon/wg-skills) 的 `frontend-style-harmonizer`、
> `mobile-uiux-spec`、`mobile-safe-area-audit` 三个 skill 的审查方法论，落到本项目
> Java / Swift / ArkTS 三端的真实组件上。原版面向 Vue / uni-app / 小程序，这里只取
> 「审查维度 + 空间责任模型 + 红线」，不引入它那套前端目录结构。

本文件回答一件事：**新界面（或改界面）之前，按什么清单自查，改完怎么验证。**
它不负责「好看」，只负责「三端一致、留白有出处、状态齐全、真机不翻车」。

---

## 一、三端单位与触控基线

| 端 | 布局单位 | 文字单位 | 最小触控目标 | 备注 |
|---|---|---|---|---|
| Android | `dp` | `sp` | 48 × 48dp | `Ui.dp()` 统一换算，禁止裸 `px` |
| iOS | `pt` | `pt` | 44 × 44pt | 视觉可小于 44，命中区不能 |
| 鸿蒙 | `vp` | `fp` | 44 × 44vp | `fp` 尊重系统字号缩放，别用 `vp` 当字号 |

硬规则：

1. **单位不混用**。跨端对齐时只对齐「设计意图」（16 留白、20 圆角），不对齐
   像素值；`1pt = 1dp = 1vp` 只能当心智模型，不能写成三端各抄一遍的魔法数。
2. **状态栏 / 安全区 / 键盘高度不许写死**，一律走端侧运行时信息
   （iOS SafeArea、Android insets、鸿蒙窗口避让区）。
3. **文字要跟着系统字号走**：iOS 动态字体、Android `sp`、鸿蒙 `fp`。

## 二、空间责任模型（本文件最重要的部分）

「看着有留白」不等于「留白有出处」。每一个间距必须回答：**由谁负责**。
同一个视觉效果，A 端由根容器 padding 给、B 端由子项 margin 凑，就是隐患——
新页面会不知道该抄谁，最后抄出一个既 padding 又 margin 的双份留白。

| 区域 | 三端统一的责任方 | 禁止的漂移 |
|---|---|---|
| 页面外侧 gutter（16） | 页面根容器 / 页签容器 | 子卡片各自 `margin` 模拟页面边距 |
| 卡片内部 padding | `Card`（16）/ `RowCard` / `GroupBox` | 页面给卡片外层 padding 反补内边距 |
| 卡片头与行的左右对齐 | 头部 icon 与下面行文字同一起点 | 头贴边、行缩进（见下方「已知坑」） |
| 底部固定栏 | `BottomBar` / 导航栏自身 + 安全区 | 内容区不预留高度，被栏盖住最后一项 |
| 键盘顶起 | 页面容器**或**输入组件，二选一 | 两层同时算一遍键盘高度 |

具体到本项目：

- **Android**：根 `Ui.dp(c,16)` 是 gutter；`Ui.card` 是卡片；`Ui.kv`/`glyphTile`
  是行与头。禁止在 `Fragment` 里手写 `16` 之外的边距魔法数。
- **iOS**：`RootView` 的 `.contentColumn(820/980)` 管最大宽度，页面自己
  `.padding(.horizontal,16)` 管 gutter；`Comp.Card` 管内边距；`BottomBar`
  参与布局（`VStack` 第二个孩子），所以**内容不需要再手动让出底栏高度**。
- **鸿蒙**：`Card`(16) 与 `RowCard` 是两种容器；`CardTitle.pad` 负责头部的
  左右留白，`SettingRow` 负责行留白。**RowCard 只给上下、不给左右**，这是
  上一版「卡片头图标贴边」的根因——新卡片头放进 RowCard 必须 `pad: 16`。

### padding 与 margin 的语义（评审时必问）

- 根容器 → 屏幕边缘：根 `padding` 负责。
- 兄弟模块之间：父容器 `gap` / Section 的 `margin` 负责，别让每张卡各背一个外边距。
- 卡片内容 → 卡片边界：`Card` 的 `padding` 负责。
- 「视觉一样但责任不同」必须写进审查结论，不能只看最终像素。

## 三、组件契约（三端同一语义必须同一形态）

新增界面先对照这组「契约」，逐条确认复用了公共组件而不是新画一份：

| 组件 | 契约要点 | 三端实现 |
|---|---|---|
| 卡片 | 20 圆角、无阴影（iOS 轻描边）、surface 底、内部 16 留白 | `Ui.card` / `Comp.Card` / `Comp.Card`+`RowCard`+`GroupBox` |
| 卡片头 | 图标 tile（28，圆角 9，accent_soft 底）+ 标题 + 副标题 | `Ui.glyphTile` / `Comp.CardTitle`(iOS) / `Comp.CardTitle`(鸿蒙) |
| 键值行 | 左 label、右等宽数字值，右值可换行不截断 IPv6 | `Ui.kv` / `Comp.KV` / `Comp.Kv` |
| 开关 | 先确认再改（DNS / 网络类），取消后视觉不得停留在新值 | `Toggle` 组件 / `Toggle` / 整行 `onClick`+只读 Toggle |
| 进度条 | 宽度用 `scaleX`/比例填充，不触发 layout | — / `Comp.Bar` / — |
| 空态 / 加载 / 错误 | 每个列表都必须有，且三端同一句文案 | 各页 `empty`/`skeleton`/`err` |

**状态清单**（每新增一个交互组件都要覆盖，缺一项算没做完）：

- 默认态、`hover`/`focus`（桌面端）、`disabled`、`loading`、`error`、`empty`。
- 深浅色各一遍。

## 四、鸿蒙专项（最容易被安卓经验带偏）

1. **单位**：布局 `vp`、文字 `fp`；别把 Android 的 `dp`/`sp` 直接抄进 ArkUI。
2. **折叠屏 / 多窗口**：`Bp`（断点）按**窗口宽度**定单双栏，不能按设备型号写死；
   旋转 / 分屏 / 折叠态都要重算，不能「算一次用到底」。
3. **`Toggle.onChange` 会被程序化改 `isOn` 触发**：数据回填也会回调。凡是
   `onChange` 里做事的开关，要么先判 `if (on !== this.xxx)`，要么像设备页那样
   把开关设成只读、点击交给整行（见 `SecurityPage` 的接管开关）。
4. **`@Watch('名字')` 是字符串引用**：死代码扫描找不到，删之前先 grep `'名字'`。
5. **`@Builder` 按值传参**：2 个以上参数时状态变化不刷新 builder 内 UI，
   要刷新用 `@Component + @Prop`。
6. **`ForEach` 的 key 必须带上会变的字段**，否则节点复用、行内容不重跑。
7. **`if` 块不能插在组件闭括号和它的 `.width()` 链式调用之间**。
8. **图标别用 `Path` 组件**：实测只画出第一个 `M` 点，统一走 `LineIcon`/`GlyphIcon`。

## 五、审查流程（改 UI 前后各跑一遍）

1. **先找真源**：颜色 `Theme.ets`/`Appearance`/`res/values/colors.xml`，组件
   `Ui`/`Comp`，别先看页面。
2. **按维度取证**：gutter / padding / 头部对齐 / 底栏 / 键盘 / 状态，逐页比对，
   记「文件:行 + 静态证据 + 责任方」。
3. **判定基线**：优先级 = 项目明确 Token > 已接入公共组件 > 稳定复用的共同实现
   > 众数（众数只当「待确认建议」，不自动当规范）。
4. **静态 vs 视觉证据分开**：静态扫描只能报「漂移 / 遮挡风险」；键盘、刘海、
   底栏最终显示必须标「待真机验证」，没有真机不得下结论。
5. **三端各验一遍**：改 UI 至少覆盖 最小屏、常规屏、深浅色、键盘弹起/收起、
   列表最后一项；鸿蒙再加 折叠/展开态。

## 六、红线

1. 审查默认只读；要改先给报告、基线，用户确认后才动。
2. **不造第二套 Token 或组件**——发现页面手写颜色/尺寸而项目已有同名 Token，
   记为实现漂移，收口到现有真源。
3. 低置信度、跨组件库、涉及交互状态的项，不自动修。
4. 对比度遵守 WCAG AA：正文 ≥ 4.5:1，大字/非文本交互元素 ≥ 3:1。
5. 报告写进本项目 `docs/`，不写进任何 skill 目录。

## 七、已知坑登记（改这里的东西先看这一节）

| 坑 | 表现 | 正确做法 |
|---|---|---|
| 鸿蒙 `RowCard` 无左右留白 | 卡片头图标贴边框 | `CardTitle` 放 RowCard 里必须 `pad:16` |
| 鸿蒙 `Card()` 自带 16 内边距 | 头部被双重留白 32pt | `CardTitle` 放 `Card()` 里**不要** `pad` |
| `Toggle` 程序化回调 | 一进页面就弹确认 | 见「鸿蒙专项」第 3 条 |
| fake-ip 下 `GEOIP,cn` 不命中 | 国内无规则站点走代理 | 用 `GEOSITE,cn,DIRECT` 兜底，别信 GEOIP |
| iOS `ZStack{背景.ignoresSafeArea();内容}` | 内容也被拉满 | 背景单独 `.ignoresSafeArea()`，内容不套 |
| Android `values-night` 同名 style | 替换不是合并 | 拆 `Theme.IStore.Base` |
