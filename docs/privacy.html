iStore Pilot 隐私政策

生效日期：2026 年 11 月 6 日 适用版本：0.3.0 及以后 开发者：chaof（个人开发者）
本政策说明 iStore Pilot（以下简称「本应用」）如何处理你的信息。
一句话概括：本应用不收集、不上传、不共享你的任何个人信息。
所有数据只在你手机和你在设置里填写的路由器之间传输。

一、本应用是什么

本应用是 iStoreOS / OpenWrt 路由器的管理客户端。它本身不具备任何联网服务端， 必须配合运行在你路由器上的 iStore Agent 使用。你需要在应用里填写 路由器的地址与登录口令，应用才能读取状态、下发设置。

本应用不是 iStoreOS 官方产品，为生态内的第三方客户端。

二、我们不收集什么

以下内容一律不收集、不上传：

  • 姓名、手机号、邮箱、身份证号等身份信息
  • 通讯录、短信、通话记录、相册、麦克风、摄像头、位置
  • 设备标识符（IMEI、OAID、IDFA、Android ID、设备序列号）
  • 应用使用行为、页面停留、点击埋点、崩溃日志

本应用没有接入任何第三方统计、广告、崩溃上报或推送 SDK。 代码中不存在向开发者或任何第三方服务器发送数据的逻辑。

三、应用会处理哪些数据（仅本地）

为了实现功能，本应用会在你的设备本地处理下列数据， 不会离开你的设备与路由器这条链路：

数据用途存放在哪
路由器地址与端口下次打开时直接连接应用私有目录（其他应用无法读取）
路由器登录口令自动登录同上
设备名、IP、MAC、流量、在线状态在界面上展示只在内存里，退出即丢
代理节点名、订阅信息在界面上展示同上（数据来自你的路由器）
拦截日志、查询记录在界面上展示同上（数据来自你的路由器）
界面偏好（主题、上次页签）记住你的选择同上

这些数据全部来自你自己的路由器，本应用只是把它们显示出来。

四、数据流向

你的手机（本应用）  ←──HTTP──→  你的路由器（iStore Agent）
                                        │
                                        └── 你的路由器本地系统（ubus / uci / nft）

链路的另一端只有你自己配置的那台路由器。填的是内网地址时，数据 不出局域网；填的是你自己的域名时，数据经过互联网到达你的路由器，但开发者看不到， 也不会经过任何开发者控制的服务器。

关于传输加密的说明：本应用与路由器之间的通信默认是 HTTP（明文）。如果你需要在 不可信网络中远程访问，请自行在路由器侧配置 HTTPS 反向代理或使用 VPN。这一点在应用内也有提示。

五、权限及用途

平台权限用途
AndroidINTERNET连接你填写的路由器地址，读取状态、下发设置
AndroidACCESS_NETWORK_STATE判断当前是否有网络，以便断网时给出提示
鸿蒙ohos.permission.INTERNET同上
鸿蒙ohos.permission.GET_NETWORK_INFO同上
iOS无敏感权限声明仅使用系统网络能力；已允许访问局域网内的 HTTP 地址

本应用不申请位置、通讯录、短信、相册、麦克风、摄像头、后台定位等任何敏感权限。

六、第三方共享

不共享。 本应用不向任何第三方提供、出售、转让你的信息。

应用内不含第三方广告、数据分析、社交分享、支付等 SDK。内置浏览器只用于打开 你自己路由器的管理页面，不会访问第三方站点。

七、你的控制权

  • 查看：应用内展示的所有数据都来自你的路由器，可直接在界面上看到
  • 修改：路由器地址与口令可在设置页随时修改
  • 删除：卸载应用，或清除应用数据，即可删除全部本地保存的信息（包括口令）
  • 撤回：不填写路由器信息，应用不会主动发起任何网络请求

八、未成年人

本应用是网络设备管理工具，不面向儿童设计，也不收集任何年龄段信息。

九、政策变更

本政策如有变更，会更新本文档并修改顶部「生效日期」。涉及数据处理方式的重大变更， 会在应用的版本更新说明中提示。
