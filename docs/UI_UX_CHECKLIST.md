# 鸿蒙 UI/UX 自检清单

> 依据：HarmonyOS Design / ArkUI 规范 + WCAG 2.1 AA，共 6 维 32 条。
> 每次发版前逐项过一遍；标 ⚠️ 的是「已按规范压到边界，改动前先量」。
> 评分卡：每维 10 分，总分 60；≥48 优秀，36–47 合格，<36 需整改。

## 一、视觉（6）

| # | 规则 | 状态 | 落地方式 |
|---|---|---|---|
| 1 | 颜色 Token 化 | ✅ | 全部走 `resources/*/element/color.json`；`Pal` 的 fallback 只在取色失败时用 |
| 2 | 字号 ≤ 8 档 | ✅ | `F_DISPLAY 44 / F_TITLE 33 / F_HERO 28 / F_H1 20 / F_H2 16 / F_BODY 15 / F_SUB 12.5 / F_TINY 11.5`，页面里禁止字面量 |
| 3 | 间距 8pt 网格 | ⚠️ | 页面留白 `PAD 16 / PAD_WIDE 24`、卡片间距 `GAP 16`、卡内 `CARD_PAD 16`；**2–6vp 的图标微调仍保留**（光学对齐，不参与栅格） |
| 4 | 圆角 ≤ 6 档 | ✅ | `R_XS 8 / R_SM 12 / R_MD 16 / R_LG 20 / R_XL 24 / R_PILL`；圆点仍用 1–6vp（几何需要） |
| 5 | 图标规格统一 | ⚠️ | 主流图标 16/17/19/20；**17/19 是描边视觉补偿**，暂未强行归到 4 档 |
| 6 | 暗色全覆盖 | ✅ | base + dark 两套色值；新增色必须同时补两套 |

## 二、交互（6）

| # | 规则 | 状态 | 落地方式 |
|---|---|---|---|
| 1 | 热区 ≥ 44vp | ✅ | 返回/关闭 44×44；小胶囊（更新/添加/启停）用 `constraintSize({minHeight:44,minWidth:44})` 撑开，视觉不变 |
| 2 | 操作有反馈 ≤100ms | ✅ | 可点文字/卡片统一挂 `clickEffect({ level: LIGHT })`（按下缩放） |
| 3 | 按钮 5 态 | ⚠️ | 主按钮有 Default / Pressed / Disabled（`enabled` + 透明度）；**Loading 只在安装、订阅更新这类异步动作里有** |
| 4 | 手势遵循平台 | ✅ | 右滑返回、下拉刷新、长按选中系统默认 |
| 5 | 危险操作二次确认 | ✅ | 卸载 AGH、重启/关机、退出接管、切换配置都先弹确认，按钮写明后果 |
| 6 | 状态保留 | ⚠️ | Tab/二级页状态保留；搜索词在页面存活期间保留，杀进程不保留（未做持久化） |

## 三、组件（6）

| # | 规则 | 状态 | 落地方式 |
|---|---|---|---|
| 1 | 组件尺寸标准化 | ✅ | 输入 44–48、按钮 ≥44、导航栏 62（含安全区外扩） |
| 2 | Props 命名统一 | ✅ | `@Param xxx` / `@Event onXxx`，不用 `isShow`、`bgColor` |
| 3 | 优先内置组件 | ✅ | 全量 ArkUI 组件；自绘仅图标（Canvas 重放路径）与趋势图 |
| 4 | 长列表虚拟化 | ✅ | 拦截日志（最多 120 条）改 `List + LazyForEach`（`core/Lazy.ets`）；设备清单仍是分组卡片（≤52 行、带分组头），暂不适用 |
| 5 | 禁止固定像素 | ⚠️ | 卡片/网口块改 `constraintSize(minHeight)`；图标与圆形按钮仍固定尺寸（几何需要） |
| 6 | 样式与逻辑分离 | ✅ | 颜色/字号/圆角/间距全走资源或 `Theme.ets` |

## 四、动效（5）

| # | 规则 | 状态 | 落地方式 |
|---|---|---|---|
| 1 | ≤500ms，微交互 ≤200ms | ✅ | 启动 380–420ms、二级页 200–220ms |
| 2 | 尊重「减弱动效」 | ✅ | `core/Motion.ets` 读 `animator_duration_scale`，为 0 时 `Motion.ms()` 返回 0 |
| 3 | 共享元素转场 | — | 二级页是页内 Shell 切换，不适用 `sharedTransition` |
| 4 | 并行动效 ≤3 | ✅ | 同一屏最多一处转场 + 一处胶囊动画 |
| 5 | 动效不触发重排 | ✅ | 只用 opacity / translate / scale，不动 width/height |

## 五、无障碍（5）

| # | 规则 | 状态 | 落地方式 |
|---|---|---|---|
| 1 | 对比度 ≥4.5:1（大字 ≥3） | ✅ | 浅色：secondary 5.63 / tertiary 5.11 / primary 4.94 / danger 5.74 / ok 6.18 / warn 5.02（白底）。深色均 ≥5.1 |
| 2 | 交互元素有语义 | ✅ | 图标按钮、页签、网口块、分组卡、列表操作都加 `accessibilityText` + `accessibilityGroup` |
| 3 | 字号 200% 不溢出 | ⚠️ | 主按钮改 `minHeight` + padding；**卡片内固定高度的行仍是 44–48**，超长文案靠 `maxLines + ellipsis` |
| 4 | 不只靠颜色 | ✅ | 状态同时有文字/图标（在线点 + 「已连接」、拦截率 + 文字结论） |
| 5 | TalkBack 全路径 | — | 需要在真机上人工走查（当前无鸿蒙真机在线），未自动化 |

## 六、多设备（4）

| # | 规则 | 状态 | 落地方式 |
|---|---|---|---|
| 1 | 4 档断点 | ✅ | `Bp.MD 600 / LG 840 / XL 1200`，`Form` 四档（xl 复用 expanded 布局 + `CONTENT_MAX 1100`） |
| 2 | 栅格响应式 | ⚠️ | 按窗口宽度算列数（自定义），未用 `GridRow/GridCol`；理由见 `ui/Breakpoint.ets` 顶部注释 |
| 3 | SafeArea | ✅ | `UI.safeTop/safeLeft/safeRight`，页面统一让出 |
| 4 | 三档真机验证 | ⚠️ | 手机已验证；折叠屏/平板未实测 |

## 发布前手检（3 分钟）

1. 浅色/深色各截一张首页，确认没有「白字白底」；
2. 字体调到最大，看设置页与拦截页按钮是否溢出；
3. 打开「减弱动效」，进二级页应无位移；
4. TalkBack 打开，从页签到二级页返回走一遍，确认都有朗读；
5. 长地址弹窗：列表脱敏、弹窗完整、可复制。
