# 鸿蒙本地自检报告 · 0.4.2（versionCode 46）

> 审核建议「用云测试 / DevEco Testing 提前自检」。云测试要在 AGC 网页手工发起
> （需要真机配额与账号操作），本机也没装独立的 DevEco Testing；
> 这里用 **模拟器 + hdc + uitest** 复刻了同一批检查项，能自动跑、能进 CI。

## 怎么跑

```bash
# Mac（模拟器已启动、hdc 能看到 127.0.0.1:5555）
bash harmony_selftest.sh                     # 默认装 entry-default-signed.hap
```

脚本做的事：装包 → 清日志 → 冷启动计时 → 勾协议进演示 → 四个页签逐个截图 +
导布局 → 打开地址弹层与订阅页 → 扫 hilog 与 faultlogger → 取 PSS →
用布局树挑出「可点但小于 44vp」的节点。

### 点击热区明细（<44vp）

| 尺寸 | 是什么 | 处理 |
|---|---|---|
| 707×39、96×32、48×18 | **系统状态栏 / 挖孔区**，不是本应用的节点 | 忽略 |
| 209×36 ×3 | 「规则 / 全局 / 直连」分段控件 | **已修**：格子 32 → 36，轨道内边距 3 → 4，整条 44vp |

分段控件横向 209vp、整条轨道都可点，实际不会误触；但按项目自己的 44vp 规矩还是抬了。

## 这次没覆盖的（需要真机或云测试）

| 项 | 为什么没做 | 建议 |
|---|---|---|
| 真机性能（帧率、滑动流畅度） | 模拟器是软件渲染，数据没有参考价值 | 装到真机用「开发人员选项 → 性能分析」看一遍 |
| 弱网 / 断网 / 超时 | 需要可控网络环境 | 路由器侧限速或拔网线手测 |
| 长时间后台驻留、内存增长 | 需要连续跑数小时 | 云测试的稳定性用例更合适 |
| 多设备形态（折叠屏展开/悬停、平板横竖屏） | 模拟器只有一个形态 | AGC 云测试可选多机型，建议上架后补一轮 |
