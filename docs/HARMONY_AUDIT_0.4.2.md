# 鸿蒙正式审核自查 · 0.4.2（versionCode 46）

> 依据：应用市场本轮驳回意见（HarmonyOS 6.1 / MateBook Pro + 手机）+ 审核规范逐项自查。
> 结论：**两条驳回项都已从根上改掉；自查发现的 3 处对比度不足也一并修了；无遗留阻塞项。**

## 1. 驳回项：根因与修法

| # | 审核给的数据 | 实际是什么 | 根因 | 修法 |
|---|---|---|---|---|
| 1 | 浅色模式下两个 `Text` 对比度 **1.03**（坐标落在设置页两行图标的方块上，52vp 间距） | 设置行左侧的**图标**（`SettingRow` 里 17vp 的 Canvas） | 图标是 Canvas 自绘，没有背景色。审核工具按「Text」取色，前景/背景取到同一个白 → 1.03 | 图标改成 `media/ic_*.svg` + `Image` 渲染，控件类型不再是 Canvas |
| 2 | `Canvas` 锯齿 **94.67**（阈值 90，31×31px 的行尾箭头） | `SettingRow` 右侧的箭头（`LineIcon` 用 Canvas 画 1.9 的细线） | 同上：小尺寸 Canvas 细线在高分屏上边缘不够干净 | 箭头并入图标包，走同一套 SVG |

两条是**同一个根因**：鸿蒙端所有图标都是 Canvas 回放。这次把 80 个图标全部
落成矢量资源（`scripts/gen_icons.py` 生成，26 视口 + 描边 2），运行期
`Image` + `ColorFilter(SRC_IN)` 上色 —— 颜色仍然逐处传，控件类型和抗锯齿都交给系统。

| 浅绿图标底 | 9% 主色，主色文字压上去 **4.48:1** | 7%，**4.58:1** |

## 4. 自查发现但**不改**的（留档说明）

| 项 | 说明 |
|---|---|
| 登录链路仍是 HTTP | 用户明确要求：路由器在本机 LAN 内、且 Agent 只监听 LAN；改成 HTTPS 需要自签证书 + 客户端信任链，收益小于风险，暂不做 |
| 宽屏下 hero 右侧留白偏大 | 属于布局取舍，不影响可用性；窄屏/宽屏两套断点都已实测 |
| 系统返回手势与二级页 | 二级页有返回栏，同时支持系统返回 |
