登录密码

App 和后端之间用一个共享口令认证，保存在 /etc/istore-agent/config.json 的 auth.password 里。 改密码最方便的方式是在 App 的「设置 → 修改控制密码」里改， 改完所有已登录设备都需要重新登录。
如果忘记密码，可以在路由器上执行下面这条命令重置： 

uci set istore-agent.main.enabled=1
python3 - <<'EOF'
import json
p = "/etc/istore-agent/config.json"
d = json.load(open(p))
d["auth"]["password"] = "新密码"
json.dump(d, open(p, "w"), ensure_ascii=False, indent=2)
EOF
/etc/init.d/istore-agent restart

重置后原来的登录令牌立即失效，需要用新密码重新登录。
